# Сборка CSS после оптимизации

- `index.html` подключает `site.min.css`. Не редактировать минифицированный файл вручную.
- Править исходные CSS. Их порядок сохранён в `tools/css-sources.json`.
- После любых изменений CSS запускать из этой папки `node tools/build-css.cjs`, затем перезагружать страницу в браузере. Скрипт обновляет сборку и её версию в HTML.
- Новый исходный CSS добавлять в нужное место `tools/css-sources.json` и пересобирать.
- При изменении изображений учитывать `srcset`/`sizes`: изменение только `src` не заменяет выбранный браузером `srcset`.
- Оригиналы изображений сохранены. Уменьшенные версии — в `assets/performance`, соответствия — в `tools/image-manifest.json`.
- Инструкции по сборке и откату: `tools/README.md`. Общие правила дизайн-системы из корневого AGENTS.md продолжают действовать.
