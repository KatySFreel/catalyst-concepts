# Сборка стилей

Страница использует `site.min.css`. Исходные CSS сохранены; порядок их подключения находится в `css-sources.json`.

После правки исходных стилей запускать из папки страницы:

```sh
node tools/build-css.cjs
```

Сборка сохраняет порядок правил, селекторы, значения свойств и условия media/supports. Удаляются комментарии и только точные повторы правил/объявлений внутри одной области каскада. Различающиеся значения свойств и браузерные fallback сохраняются. Результат повторно разбирается и сравнивается с деревом CSS до минификации. Версия подключения в `index.html` обновляется автоматически.

Зависимости указаны в `tools/package.json`; в текущем рабочем пространстве используются уже установленные PostCSS и Sharp из `sites/catalyst-copy-review/node_modules`. На другом компьютере выполнить `npm install --prefix tools`.

## Изображения

Оригиналы не перезаписаны. Облегчённые варианты лежат в `assets/performance`, карта соответствий и размеры — в `image-manifest.json`. В HTML используются `srcset`, `sizes` и размеры оригиналов для резервирования пропорций. Динамические изображения первого экрана сохранены без статического `srcset`, чтобы смена `src` в слайдере не оставляла на экране предыдущую картинку.

`optimize-images.cjs` и `prepare-preview.cjs` использовались для первичной подготовки из HTML с исходными ссылками. Не запускать их повторно поверх уже оптимизированного HTML; при повторной подготовке использовать исходник из резервной копии.

## Проверка и откат

Исходная резервная копия: `output/optimization-backup-20261104-180506` от корня проекта. Актуальный HTML непосредственно перед подключением сборки сохраняется дополнительно в `output/optimization-qa/index-before-publish.html`. Скриншоты и измерения браузера находятся в той же папке проверки.

Для отмены только этого изменения восстановить `index-before-publish.html` как `index.html`: исходные CSS и изображения оставлены на месте. Не восстанавливать старые JS поверх параллельных правок.

`canonical` и `og:url` рассчитаны на публикацию в корне `https://catalystrussia.ru/`. Социальное превью загружается вместе с `assets/performance/social-formula-1.jpg`. У черновика сохранён `noindex, nofollow`; разрешение индексации выполняется отдельно при публикации.
